说明

  1. 设置目录：第一次打开时选择「存档目录」和「游戏目录」，两项都通过后点「开始使用」。以后可点右上角齿轮修改。
  2. 选择存档：在左侧「当前存档」里点选要修改的存档。
  3. 获得物品：在搜索框输入物品名，或点分类标签；在卡片上点「获得」，在确认框里选品阶或款式（可叠放物品填数量）后确认。
  4. 回游戏读档：回到游戏读取这个存档，新物品就在背包里。

想留后路？先点「加入备份区」，出问题可在「备份区」一键还原。

获得后游戏里看不到？
需要在游戏里重新读取这个存档。另外，游戏运行时如果又存到同一个存档位，会覆盖掉修改，建议在主菜单读档前使用。
开了 Steam / GOG 云存档会有影响吗？
修改后启动游戏时，如果平台弹出云存档冲突提示，请选择保留本机存档，否则修改会被云端的旧存档覆盖。不确定时，先把存档加入备份区。
物品库是空的或提示名字表不可用？
需要安装官方免费 DLC REDmod（Steam / GOG / Epic 均可获取），并在设置里选对游戏目录。
没买往日之影能用吗？
可以。工具会检测游戏目录：没有往日之影时，物品库只列本体物品，往日之影的物品不显示、也不会生成。设置里游戏目录一行会显示检测结果。
存档显示「不支持」？
分两种情况：
  • 旧版本的存档：在游戏里读取后重新存档即可。
  • 游戏更新后的新版本存档：工具需要适配新版本，暂时不能修改（这是保护存档的安全设计）。请关注作者 B 站获取更新。
怎么备份和还原？
选中存档后点「加入备份区」；在「备份区」页签里可以查看、还原或删除备份。获得物品不会自动备份。
会不会把存档改坏？
每次写入前都会逐字节校验：除了新增或修改的物品，其他内容只要有任何变化就放弃写入，原存档保持不变。
如何查看已拥有/未拥有的物品？如何多选批量添加？
  • 状态筛选：分类栏下方提供「全部 / 未拥有 / 已拥有」切换，点击「未拥有」可直接查看当前存档还未收集的所有装备，分类标签上的数字也会实时同步为未收集数量。
  • 批量选择模式：点击工具栏的「批量选择」按钮进入多选模式，直接点击多张物品卡片进行勾选，在底部浮动操作条中选择存放位置后，点击「一键获得」即可一次性全部注入存档。
为什么获得不朽武器推荐选「放入储藏室」？升阶到 5++ 的机制是什么？
这是由于《赛博朋克 2077》2.0+ 官方脚本的等级校准机制（RescaleStashedIconicsToPlayerLevel）：
  • 游戏机制规定：不朽武器升阶到 5++（传说++）需要角色达到 51 级以上并拥有《往日之影》，且武器的掉落等级必须经过游戏引擎校准。
  • 直接放入背包的注入武器缺少掉落时的时间戳校准，在工坊升到 5 阶后会无法继续升级到 5++。
  • 解决方案：选择「放入储藏室」，修改后进游戏从载具后备箱或公寓储藏点将武器取出，游戏原生脚本就会自动触发等级校准，使其完美解锁 5++ 升阶！
我们的设计理念：为什么没有载具、任务物品、技能点？
这是本工具核心的「极致安全、免注入、防坏档」设计理念：
  • 载具（车辆/摩托）：游戏底层载具归属于独立状态机系统，强行在存档注入极易破坏召唤逻辑导致坏档。最安全、符合游戏规则的做法是：在物品库最后一栏「货币」里给背包添加任意欧元，然后在游戏内「好车中间人」终端全款买齐，体验原汁原味的提车仪式感且绝不坏档。
  • 任务剧情物品：主线特定芯片、超梦头环等带有任务脚本锁，强行注入背包会导致剧情触发紊乱或主线卡关。为了保护玩家百小时存档安全，工具特意严格过滤。
  • 技能点 / 属性点：属于人物角色成长系统，本工具专注于打造安全、直观、即插即用的纯外部物品库，不碰复杂的角色内部状态。
物品库全吗？为什么有些物品搜不到？
全网最全！工具在启动时实时动态扫描本机游戏官方 REDmod 数据库，完整收录 13 大类 3,900+ 件物品，包括全系不朽武器、不朽近战、全义体与高级图纸，一件不漏。若搜不到请注意：
  • 搜官方全名：请使用官方标准中文名或简短关键词检索（例如搜「四季宝」、「寡妇制造者」）。
  • 同名款式与品阶折叠：多品阶装备或同款多涂装（原版/霓虹/军用等）自动智能合并为同一张卡片，点击「获得」可在确认弹窗中自由切换款式与品阶（默认即为最高阶传说++）。
  • 资料片专属隔离：未购买安装《往日之影》DLC 时，工具会自动隐藏资料片专属物品，防止生成后游戏识别异常。
核心理念：为什么不做数值修改（攻击力、无敌、秒杀等）？
尊重游戏本体的游玩体验是本工具的核心立项宗旨：
  • 纯净调取，拒绝魔改：本工具只严格按官方数据结构规范，调取游戏本体原生存在的装备、外观与资源，绝不修改武器攻击力、暴击率、角色血量或无敌秒杀等底层数值。
  • 保留探索乐趣：我们希望帮助玩家轻松获取心仪的外观搭配、补齐错过的标志性收藏，同时最大程度保留夜之城的战斗平衡、build 构筑乐趣与原汁原味的沉浸感。
